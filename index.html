ONE CONNECTED WORKFLOW

一个商品，沿着一条生产线往下走。

左边看步骤，右边看工具怎样接住上一环节的结果。素材不必反复上传，提示词不必来回复制。

01 / 05选品与采集

先把商品带进来。

导入商品链接，或通过本地浏览器采集插件读取已登录页面中的标题、价格、主图和规格。同一链接再次采集会更新原商品。

  • 候选商品与来源保留
  • 类目、价格和状态筛选
  • 悬停快速预览
02 / 05提示词工程

图片和视频，不再用同一套词。

根据用途生成电商提示词，历史记录明确标注“图片提示词”或“视频提示词”，生成后可一键导入对应工作区。

  • SKU / 主图 / 视频类型标签
  • 商品事实和卖点约束
  • 一键导入，不再复制
03 / 05商品生图

商品身份不变，表达快速换。

主图详情图与 SKU 图独立配置。红木商品内置 15 个小类目规格参考和 4 张中式背景，上传时可从素材中心或本地选择。

  • 精确比例与像素尺寸
  • 15 类红木规格模板
  • 4 张背景参考入口
04 / 05商品视频

先看清线路，再提交任务。

根据参考图片、视频、音频和用途选择线路，画幅、清晰度、时长与预估成本联动。结果在右侧抽屉中保持原始比例预览。

  • 动态线路与能力说明
  • 任务进度和真实结果
  • 9:16 竖屏抽屉预览
05 / 05素材沉淀

这次的结果，是下次的素材。

生成图片和视频自动回到素材中心。搜索、文件夹、批量移动、带声音预览和真实创建时间，让内容可以继续复用。

  • 六类素材统一管理
  • 本地文件夹与 SQLite
  • 搜索结果点击外部关闭

BUILT FOR DAILY ECOMMERCE WORK

不是一排 AI 按钮，
是每天都能重复使用的工作台。

功能配置围绕商品内容生产展开：事实先进入，生成任务有记录，最终结果回到素材库。

01
本地素材中心

图片、视频、音频放在同一个地方。

支持拖拽导入、悬停预览、文件夹、标签搜索、批量移动、替换文件和回收站。视频预览保留声音，结果可直接用于下一次生成。

02任务中心

进度、结果与失败原因可追踪。

远端任务按 ID 去重，自动轮询和手动查询共享状态，避免重复提交和重复扣费。

03本地浏览器插件

采集你已登录页面里的商品信息。

连接桌面工作台后，读取标题、价格、主图与规格，并保留来源。

04线路配置

把模型能力翻译成用户能看懂的选项。

参考素材数量、真人能力、比例、清晰度、时长、并发和费用会随线路变化。

05
本地优先

文件留在电脑，密钥由系统加密保存。

大文件保存到你选择的文件夹，SQLite 记录工作台状态。未配置接口时，收费生成会明确停止。

FAQ

下载前，先把关键问题说清楚。

下载后能直接生成图片和视频吗？+

素材管理和本地工作台可以直接使用；真实生成需要在软件中配置自己的图片、视频线路和 API Key。

为什么手机号登录还不能正式发验证码？+

软件内已保留登录流程，但国内生产短信需要合规企业主体、签名和模板。当前测试版没有把固定测试流程包装成正式短信服务。

生成结果保存在哪里？+

图片和视频默认保存到你选择的本地文件夹，并自动出现在素材中心；可选云端只同步任务与素材元数据。

Windows 为什么可能提示未知发布者？+

当前版本尚未购买商业代码签名证书。请只从本页面下载，并核对版本号和文件哈希。

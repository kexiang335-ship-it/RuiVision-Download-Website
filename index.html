WHAT RUIVISION DOES

RuiVision 到底做什么？

它把电商内容生产拆成四个清楚的阶段。每一步都接住上一步的结果，最后回到本地素材库继续复用。

01 / 04商品进入

把商品资料带进工作台。

粘贴商品链接，或使用浏览器采集插件读取已登录页面中的标题、价格、主图和规格。采集结果先进入候选池，确认后再生产内容。

  • 商品链接导入
  • 浏览器采集插件
  • 同链接更新与人工审核
02 / 04素材准备

把素材和商品事实整理清楚。

本地图片、视频和音频统一进入素材中心；商品名称、卖点与规格进入提示词工程，并按图片或视频用途一键送到对应生成区。

  • 六类素材统一管理
  • 图片 / 视频提示词分型
  • 素材中心与本地双入口
03 / 04内容生成

生成商品图，也生成商品视频。

主图、详情图、SKU 图各自使用合适的参考结构；视频根据素材、比例、清晰度、时长和成本选择线路。生成前先看清配置，生成后保留原始比例预览。

  • 主图 / 详情图 / SKU 图
  • 15 类红木规格与 4 张背景
  • 多线路视频与 9:16 预览
04 / 04任务与沉淀

看清进度，把结果留下来。

任务中心记录生成状态、成本、结果和失败原因；完成的图片与视频自动保存到本地文件夹和素材中心，下一次可以直接继续使用。

  • 任务进度与结果查询
  • 本地文件夹和 SQLite
  • 生成结果自动进入素材库

FAQ

下载前，先把关键问题说清楚。

下载后能直接生成图片和视频吗？+

素材管理和本地工作台可以直接使用；真实生成需要在软件中配置自己的图片、视频线路和 API Key。

为什么手机号登录还不能正式发验证码？+

软件内已保留登录流程，但国内生产短信需要合规企业主体、签名和模板。当前测试版没有把固定测试流程包装成正式短信服务。

生成结果保存在哪里？+

图片和视频默认保存到你选择的本地文件夹，并自动出现在素材中心；可选云端只同步任务与素材元数据。

Windows 为什么可能提示未知发布者？+

当前版本尚未购买商业代码签名证书。请只从本页面下载，并核对版本号和文件哈希。
